# 構成（2026-11-03 決定）

| 決めたこと | 内容 | 理由 |
| --- | --- | --- |
| 言語 | TypeScript。画面は React + Vite | 画面とスケジューラを同じ言語で書き、同じ計算を使い回す |
| 置き場所 | Cloudflare Workers 1つで画面と API を配る（公式テンプレート `create-cloudflare --framework=react`） | 公開するときは URL が1つで済む |
| データ | 架空のサンプルを、使う人のブラウザに保存する | ログインも共有の DB もいらない。個人情報を持たない |
| スケジューラ | `src/engine/` に純粋な関数として書き、Vitest でテストする | 同じ入力なら必ず同じ計画になる |
| ガント | React で SVG を描く | 設備×時間の表示と、Lot を押したときの動きを自由に作れる |
| Claude | Messages API のツール呼び出し。ツールはブラウザで実行し、Worker は中継だけをする | Claude が「変更を当てる → 計画を作り直す → 前後を比べる」を道具で進める |
| 鍵 | API キーは Worker の secret にだけ置く。中継ではモデル・指示文・道具・出力の長さを固定し、回数を制限する | 公開した窓口が、誰でも使える中継にならないようにする |
| パッケージ | npm | ローカルで動かすとき、追加の道具がいらない |

## フォルダ

```
src/            画面（React）
src/engine/     スケジューラと計算。React を使わない
worker/         Claude との中継と回数制限
sample-data/    架空のサンプルデータ
docs/           この記録と開発メモ
```

## データ

- 工程表：型番ごとの工程の並び
- 注残：注番・型番・数量・納期
- Lot：Lot番号・注番・数量・今いる工程・その工程に着いた日

工程ごとの完了数・仕掛・未着手・完成は、Lot から計算する（`src/engine/progress.ts`）。未着手は、注残の数量のうち、まだ Lot にしていない数。
